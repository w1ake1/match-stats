# CS 赛事查询系统 · IEM 科隆 Major 2026

一个单文件、零依赖的 CS2 赛事查询前端页面。以 **IEM 科隆 Major 2026** 为主题，展示四强战队、选手雷达、外设装备与选图对位。

## 快速开始

双击 `index.html` 即可在浏览器打开（无需构建、无需服务器、无外部依赖）。

## 功能

**赛事概览**
- 赛事头条：名称、时间、场馆、队伍数、奖金池、赛制、观赛数据
- 四强战队卡片：名次（冠军/亚军/四强）、赛区、世界排名、首发五人、晋级之路
- 半决赛对阵：逐图比分、全场 MVP；单列金色描边的总决赛卡片
- 赛事数据条 4 项

**选手雷达**
- 4 队 × 5 人 = 20 名选手
- 每人一张 6 维雷达图：火力 / 狙击 / 突破 / 支援 / 残局 / 道具
- Rating、ADR、KAST、爆头率等指标
- 徽标：赛事 MVP、决赛 MVP、EVP 等
- 支持按战队筛选

**外设装备**
- 20 名选手的鼠标 / 键盘 / 耳机 / 显示器 / 鼠标垫 / eDPI 表格
- eDPI 附 `DPI × 灵敏度` 明细，支持按战队筛选

**选图对位**
- Veto 选图流程（7 步 ban/pick，含决胜图）
- 地图池与地图胜率对比条
- 头对头对位：狙击对位 / 突破手对位 / 指挥·自由人对位

## 数据来源说明

| 数据 | 来源 |
|---|---|
| 赛事信息、四强名单、比分、逐图结果、选图 | **真实赛果**（已联网核对 ESL / Liquipedia / esports.gg） |
| 雷达图数值、外设装备、对位数值 | **演示数据**，由「战队 + 选手」作种子确定性生成 |

页脚已注明：部分数据为演示生成，非真实统计。

## 交互与动效

- 点击涟漪：全站按钮从点击坐标扩散径向光斑
- 高光扫过：鼠标悬停时斜切渐变横向掠过
- 按下回弹：`scale(.955)` + 弹性缓动
- 滑动墨块：Tab 与筛选按钮底部指示块平滑滑动，并随窗口缩放自动重算
- 查询按钮：提交时转圈显示「查询中」，空输入时搜索栏抖动提示
- 深/浅主题切换、URL 直达参数 `?q=<选手或战队名>`
- 已适配 `prefers-reduced-motion` 无障碍降级

## 技术说明

- 单个 `index.html`，HTML + CSS + JS 全部内联
- 图表（雷达图 / 对比条）使用原生 SVG 手绘，零第三方库
- 数据结构见脚本顶部 `EVENT` / `TEAMS` / `MATCHES` / `PLAYERS` / `MAP_POOL` 常量

## 接入真实数据

当前为纯前端演示。若要接入后端，把数据生成逻辑替换为 `fetch()` 调用真实赛事 API 即可，渲染层无需改动。
